# 進階版 0.2.0-beta.6：Rust 原生錄影核心實驗版

保留現有介面與原有相容模式，新增「錄影進階設定 → 錄影核心 → Rust 原生核心」。

- Windows Graphics Capture 原生擷取螢幕／視窗，避開 Canvas／MediaRecorder 與 WebM 中間編碼。
- MP4／MKV、H.264／H.265、固定 30 FPS、暫停／繼續及原有快捷鍵。
- 自動探測 NVENC／QSV／AMF 硬體編碼；沒有可用裝置時使用 CPU，也可手動選 CPU。
- Windows 預設播放裝置的系統音訊、預設麥克風與混音。
- 停止後合併音訊，影片不再重編；播放器與剪輯功能保留。

## 第一次測試

選擇 Rust 核心、即時儲存、MP4、H.264，關閉內建攝影機與浮水印。選擇整個螢幕即可錄入另外開啟的網路攝影機工具視窗。
先錄 2–3 分鐘，包含說話、播放系統音訊、暫停與繼續，再檢查聲畫同步。

## 第一版限制

WebM、框選範圍、內建攝影機合成、去背、浮水印及指定麥克風仍請使用原有相容模式；原生模式會明確提示不支援的組合。原有模式仍為預設。
原生錄影期間不顯示即時預覽。視窗尺寸固定為開始時大小，請避免調整尺寸或最小化。
音訊暫存約 0.69 GB／小時／48 kHz 雙聲道來源，合併時需額外磁碟空間；成功後會清除暫存，失敗保留復原資料。
此版仍包含 GPU 到 CPU 的畫面讀回，尚非零複製核心。效能、硬體編碼及長時間聲畫同步需依實際電腦驗證，不保證改善既有外部攝影機掉格。
