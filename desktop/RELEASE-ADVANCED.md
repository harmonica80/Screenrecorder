# 進階測試版 0.2.0-beta.3

- 內建原生 FFmpeg，支援即時 MP4（H.264／AAC）、MKV 與 WebM 儲存。
- 保留先錄 WebM 再轉檔模式，支援裁切、分割、音量調整、取消處理與 MKV 無損封裝。
- 更新應用程式與工作列圖示。
- 頁尾加入 GitHub 專案連結與網頁版／輕量版／進階版介紹，外部連結使用系統預設瀏覽器。
- 更新進階版格式說明。

適用 Windows 10／11 x64。先關閉舊版，再開啟免安裝 EXE。
MP4 即時編碼較耗 CPU。精準剪輯與音量調整仍可能重新編碼，MP4／MKV 不保證每次都大幅加速。Windows 擷取與長時間穩定性仍需實機測試。
