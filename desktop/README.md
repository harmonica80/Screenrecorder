# Windows 免安裝輕量版

此版本以 Electron 執行現有錄影介面，錄影資料會每秒串流寫入使用者選定的 WebM 檔案，不會將完整錄影長時間保存在記憶體。

## 開發測試

```bash
npm install
npm start
```

## 建立 Windows Portable

```bash
npm run dist:win
```

成品會建立於 `release/Screenrecorder-Pro-Lite-0.1.4-Portable.exe`。

## 0.1.5

- 全域錄影快捷鍵：預設 F9 開始／暫停、F10 停止。重複按住不會連續觸發；按鍵被占用時顯示提示。修改按鍵時暫停註冊，離開欄位後重新註冊。
- 桌面剪輯改用獨立影片播放器、Canvas 與 Web Audio 重新輸出 WebM，分塊寫入磁碟；不再呼叫 FFmpeg WASM。裁切、分割、音量調整共用此流程，耗時接近片段長度。
- 移除來源縮圖固定高度造成的黑邊；瀏覽器分頁選項改為自訂錄影範圍，先選螢幕，再於預覽拖曳框選。
- Electron 無畫面測試：4 秒含音訊影片裁出 1～3 秒，產生約 1.98 秒 WebM；前半靜音、後半有音訊。Windows 全域按鍵與螢幕擷取仍需實機驗證。

## 0.1.4

- 左側底部新增「儲存上次錄影設定」（預設勾選）及「重設為預設值」。錄影設定保存於應用程式設定檔。
- 頁尾新增實際版本號與 GitHub Releases 更新檢查；需發布正式版本並附上 Portable EXE 才可比對。檢查失敗或尚未發布會明確提示。
- 隱私與使用說明改為桌面版描述，說明直接寫入磁碟、WebM 及選用連線功能。
- 桌面版固定左右欄，移除寬度門檻造成的上下堆疊。
- 已完成的錄影經由本機 HTTP Range 串流播放，避免 HTTP 頁面載入 file URL 被阻擋。
- 錄影進階設定可選擇預設儲存資料夾；設定保存於應用程式設定檔，重啟後仍有效。同名檔案另加編號。
- Windows 工作列顯示閃爍紅點；暫停黃點，結束移除。
- 編碼選單只顯示 WebM 選項；此版不支援 MP4 轉檔。
- 驗證：`node --test desktop/*.test.js`。Windows 擷取、音訊與工作列視覺仍需實機驗證。

## 輕量版限制

- 僅輸出 WebM，以使用 Chromium 原生 MediaRecorder，未內建 FFmpeg。
- 錄影完成可直接播放，並可從程式開啟檔案所在資料夾。
- 為避免大型影片重新載入記憶體，桌面版錄影完成後不自動建立音訊波形與剪輯縮圖；可使用「載入本機影片剪輯」處理短片。
- 未簽章的測試版在 Windows 可能出現 SmartScreen 提示。
